# styleable() audit (Tamagui v3 flatten-first)

Per conventions §5: (A) = pure prop→style mapping, converted to / kept on plain `styled()` (+ static variants, `styled.dynamic`); (B) = real behaviour, kept on `styleable()`. Each wave agent appends its own section.
